# Laptop GDN Stüdyosu

1–3 laptop için GDN HTML5 banner seti (8 boyut) üreten tarayıcı uygulaması.

Boyutlar: 160×600, 300×250, 300×600, 320×480, 336×280, 728×90, 720×1280, 970×250

## Kurulum

```bash
npm install
npm run dev
```

Tarayıcıda http://localhost:5173 açılır.

## Kullanım
1. Soldan kampanya adı, tıklama adresi ve buton metnini gir.
2. Arka plan ve logo yükle, renkleri ayarla.
3. 1–3 laptop ekle; her biri için görsel, ad, model, fiyat ve en fazla 3 özellik.
4. Sağda 8 boyutun canlı önizlemesi var. "Boyutları ölç" her ZIP'in 150 KB sınırına göre durumunu gösterir.
5. "Tüm seti indir" her boyut için ayrı ZIP içeren tek bir paket indirir. Her iç ZIP doğrudan Google Ads'e yüklenebilir.

Geliştirme notları için `CLAUDE.md` dosyasına bakın.
